Feature Summary

Build performance-ready sound grids in seconds

Launch and layout

  • Instant patch launch from a visual 4 x 4 slot grid
  • Multi-page PatchGrids for larger sound sets
  • One-touch selection sends the chosen patch directly to the M3
  • Dedicated Play view for quick access during performance
  • Dedicated Edit view for building and managing PatchGrids
  • Lock or unlock slot-grid dragging in Play view
  • Template PatchGrids can be filled from enabled INT and USR banks
  • Settings includes MIDI routing, filtering, Bi-directional, Learn, Config, and Patch Library tools
  • Expandable MIDI Activity strip shows Program Change, Bank Select, CC, SysEx, and note information
  • KARMA information strip shows the current patch setting above the large PROG/COMBI name

Sounds and storage

  • Stores both PROG and COMBI patches in the same PatchGrid workflow
  • Up to 16 slots per page
  • Up to 8 pages per PatchGrid
  • Up to 128 saved PatchGrids
  • Default PatchGrid auto-populates starter sounds from PROG and COMBI categories
  • Default PatchGrid includes starter notes explaining its sample sounds

Per-slot control

  • Per-page, per-patch performance-control overrides
  • Saved controls include Tempo, Volume, EQ, Transpose, SW1, SW2, Drum Track, and KARMA
  • Save recalls the selected patch's controls and highlights when an override is active
  • 16 slot colours with Auto Colour and quick two-tap colour selection
  • In Play view, drag up or down for category-specific patch changes and left or right for bank-specific patch changes
  • Search and assign patches by name or number from the Play view

Patch search and assignment

  • Find patches instantly by name or number with intelligent word matching
  • Filter by PROG, COMBI, bank, GM, category, and subcategory
  • Preview patches and browse grouped results before assigning
  • Assign multiple patches to selected pages and slots without closing Search
  • Change slot colours directly from the mini grid

Performance and navigation

  • Empty slots can also be populated by dragging through patches
  • Independent reorder modes for PatchGrids and pages with saved ordering
  • Play view uses a 2 x 2 PatchGrid selector with arrows inside its width
  • Selected slots use a thicker outline for clear identification

Editing and management

  • PatchGrid naming with duplicate-name protection and input validation
  • Rename, duplicate, clear, and hide PatchGrids
  • Combined reorder icon with yellow active state and visible drop position
  • Duplicate and clear individual pages
  • Copy and paste single slots between positions
  • Remembers the last selected page and slot when reloaded
  • Saves PatchGrid data, slot settings, colours, and notes to file
  • Notes support up to 500 characters with a remaining-character counter and scrolling

Bi-directional M3 control

  • Bi-directional settings control incoming Drum, KARMA, and Patch messages
  • MIDI Learn assigns incoming messages to Volume, EQ, Switch, Transpose, Slot, KARMA, Module, Scene, PatchGrid, PatchList, and Mode
  • Patch selections made on your M3 are recognized instantly by type and reflected in the selected PatchGrid slot

Modal popups

  • Tempo popup provides keypad entry, a round encoder, fine tuning, and favourite tempo selection
  • KARMA Controls popup provides KARMA Drum Link, Latch On/Off, Module, and Scene selection using direct buttons or previous/next sequential controls

Supported Hardware Configurations

  • Supports both Lightning and USB-C iPad connection types

PatchGrid Help Manual

Build and perform with PatchGrid

Use PatchGrid to organise Korg M3 PROG and COMBI sounds into fast, visual performance layouts.

Launch and layout

  • Launch patches instantly from the visual 4 x 4 slot grid.
  • Use multiple pages for larger sound sets.
  • Select a slot once to send its patch directly to the M3.
  • Use the Play symbol for performance and the Grid icon for building PatchGrids.

Sounds and storage

  • Store PROG and COMBI patches in the same PatchGrid workflow.
  • Each page supports up to 16 slots.
  • Each PatchGrid supports up to 8 pages and 128 saved PatchGrids.
  • Starter sounds can be loaded from PROG and COMBI categories.
  • The Default PatchGrid includes starter notes.

Per-slot control

  • Save Tempo, Volume, EQ, Transpose, SW1, SW2, Drum Track, and KARMA per slot.
  • Colour slots for fast visual grouping.
  • Search and assign patches from the Play view by name, number, type, or bank.
  • Enable template PatchGrids from Settings > Config > Grid/Pages.

Editing and management

  • Rename, duplicate, clear, hide, and re-order PatchGrids and pages.
  • Copy and paste individual slots.
  • Notes are limited to 500 characters and remain scrollable with a live counter.
  • PatchGrid remembers the last selected page and slot after reload.
  • Save PatchGrid data, slot settings, colours, and notes to file.
